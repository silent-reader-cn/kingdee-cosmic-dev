# API1.0 下架【新增】按钮

1 简介

1.1 重要通知

API服务管理列表1.0 下架新增按钮，建议二开接口使用全新API2.0版本。

**适用版本：V5.0.005（BOS）**

## 1.2 系统路径

【开发服务云】→【开放平台】→【其他】 →【API服务管理1.0】

2 功能截图

2.1 打开API服务管理1.0列表

列表中默认不展示【新增】按钮，用户只能修改原接口，无法新增。

![](https://vip.kingdee.com/download/0109cb4ebcd042804f57bc996ec46f314021.png)

2.2 显示新增按钮

若用户仍坚持使用API1.0接口进行新增，可进入参数配置界面，路径：【开发服务云】→【开放平台】→【参数配置】，打开新增按钮显示开关（不建议），后续产品会下架该开关。
![](https://vip.kingdee.com/download/0109607b262e5fd943e08c1f6489e80d1293.png)
