# 保存操作API权限增强校验

## 变更记录

| 产品版本 | 更新内容 | 更新日期 |
| --- | --- | --- |
| V7.0.7 | 保存操作API增加“保存权限项自动校验”开关，提升API安全性 | 2025年03月11日 |

## 1 背景说明

此前，通过OpenAPI 执行单据或基础资料的新增、修改操作时，若元数据保存操作没绑定权限项，则即使用户未被授予相关权限，在注册第三方应用并授权API接口权限后，仍可通过 API 执行新增或修改操作。

## 2 功能升级

- 新增API级权限开关：在 API 配置界面中，增加 【**保存权限项自动**校验】开关， 新增时开关默认打开。
- 开启后生效规则：
  - 新增数据：调用 OpenAPI 时，系统将校验用户是否拥有该单据类型的 “新增”权限。
  - 修改数据：调用 OpenAPI 时，系统将校验用户是否拥有该单据类型的 “修改”权限。
  - 权限缺失拦截：若用户无对应权限，API 将返回错误码 603，并提示无“XXX”的“新增”或“修改”权限。

## 3 操作指引

### 3.1 操作路径

- 开放服务云 → OpenAPI → API管理 → API开发，在API详情界面配置项中，开启 【保存权限项自动校验】。

![](https://vip.kingdee.com/download/01097f02acf63fe74553a04f765fb40a92c2.png)

### 3.2 启用建议

- 建议开启场景：
  - 您的业务对数据操作权限有严格管控要求。
  - API 涉及财务、库存、客户信息等敏感单据。
- 暂不建议开启场景：
  - 存在历史遗留 API 依赖原有逻辑（需先评估权限适配性）。

## 4 核心价值

- 安全性提升：杜绝未授权用户通过 API 越权操作关键业务数据。
- 合规性完善：满足企业内部审计或外部监管对数据权限的强制要求。
- 灵活性可控：您可根据业务需求自主选择是否启用此功能。

## 5 注意事项

- 影响范围：此功能仅对配置后新发起的 API 请求生效，不影响已发布的历史 API。
- 兼容性：开启后，请确保调用 API 的终端用户已配置正确的功能权限（通过安全管理模块检查）。
- 回滚操作：关闭开关即可恢复至原有逻辑，无需重启服务。
