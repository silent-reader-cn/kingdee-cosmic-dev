# 开放平台API日志默认保存30天

发布说明

发布版本：苍穹V5.0

适用范围：苍穹开放平台所有用户

上线日期：2023-04-27

补丁号：V5.0.020（BOS）

 更多内容

 变更记录

| 产品版本 | 更新内容 | 更新日期 |
| --- | --- | --- |
| V5.0.020 | 开放平台API日志定时清理 | 2023年4月27日 |

开放平台提供了API调用日志功能，用于分析及审计API调用情况。 为提升用户使用体验及存储性能，自5.0.020补丁开始，开放平台对API调用日志默认只保存30天，且最多保留500万行。 用户可在开放平台参数设置菜单，配置日志保留天数最长至90天。

如果您需要保留更长时间的API调用日志，您可以参考下述文档配置 API日志转储归档策略。

帮助文档金蝶AI苍穹V5.0_开放平台-日志清理配置指南.pdf
