# API菜单迁移及版本升级通知

发布说明

发布版本：苍穹V5.0

适用范围：苍穹开放平台所有用户

上线日期：2022-06-18

补丁号：V5.0.002（BOS）

 更多内容

## 重要通知

致金蝶AI苍穹开放平台所有用户：

在金蝶AI苍穹V5.0版本中，开放平台推出了全新的OpenAPI引擎（v2）。因此，为了分开管理不同版本的接口，**API1.0菜单迁移到【其他】-【API1.0】**下。历史版本的接口和API清单统一在这里进行管理，并且仍然能正常使用。

OpenAPI新版本增强了API的安全性以及易用性，能以更低成本将实体对象快速配置出符合OpenAPI规范的API，支持使用自定义API处理更复杂的业务逻辑。**同时针对历史已发布的API，产品会支持接口一直兼容，以保障业务的连续性**。
