# 开放事件介绍

# 1 概述

开放事件（OpenEvent），通过事件消息**实时主动向外传递**苍穹平台业务数据变更情况，使对接系统得以即时、个性化响应，**避免频繁的API轮询**。各领域通过此服务开放标准业务事件，**增强平台的开放性**，促进数据高效流通与共享，推动业务的快速发展与创新。

# 2 适用场景

**1、将平台能力开放**
通过开放事件，将平台的营销、供应链、财务等领域的数据变化开放，第三方系统按需集成，对平台无侵入。

**2、多场景数据集成**
事件驱动系统间业务协同，如主数据同步、销售采购关联交易、库存同步等等业务集成场景。

**3、消息通知和告警**
适用于消息通知、事务协作、异常预警、监控、广播等场景。

# 3 业务流程
当业务人员操作业务单据时，开放平台监听操作事件，然后根据事件推送订阅，将事件消息通过回调Webhook接口传递到第三方系统。

# 4 业务价值

- **解决系统间实时互通问题**：苍穹某个操作或变化发生时立即触发事件，通知相关的应用程序或用户，以便及时采取相应的措施或处理，彻底告别API轮询方式。
- **增强对接灵活性和可扩展性**：事件集成降低平台与第三方系统的耦合度，第三方系统按需订阅，不涉及代码变动，更好地适应不断变化的业务需求。
- **提升苍穹平台开放性**：开放事件提供开箱即用的标准事件服务，有助于加速平台开放性建设，促进平台生态繁荣。
