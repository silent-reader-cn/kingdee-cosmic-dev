# 脚本调试介绍

1 简介

1.1 功能介绍

OpenAPI提供帮助开发人员调试脚本的工具，该工具在生产环境中无法使用。

1.2 应用场景

帮助用户快速调试脚本，提升接口开发效率。

1.3 系统路径

【开放服务云】→【OpenAPI】→【其他】→【脚本调试】

1.4 按钮说明

| 按钮名称 | 详细解释 |
| --- | --- |
| 执行 | 点击按钮，执行当前代码片段逻辑。 |
| 退出 | 点击退出按钮，退出当前页面。 |

2 主要操作

2.1 调试脚本

首先，开发人员需要编写并维护好脚本。然后，找到脚本调试工具，点击“调试”按钮即可查看测试结果。
