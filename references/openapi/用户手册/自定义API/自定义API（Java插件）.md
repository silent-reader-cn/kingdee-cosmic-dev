## 1. 简介

### 1.1 功能介绍

自定义API主要通过Java插件来解决复杂的API集成场景，如调用微服务或对文件流、图像等进行处理。用户预先定义类和方法，通过简单配置，快速生成自定义API，开发案例参考 [自定义API开发](https://dev.kingdee.com/open/detail/sdk/2000919573355839488)。

### 1.2 应用场景

发布API接口供第三方应用调用，帮助用户快速完成苍穹平台与异构系统间的数据集成。

### 1.3 系统路径

【开放服务云】→【OpenAPI】→【API管理】**→**【API开发】

## 2. 主要操作

### 2.1 打开API服务管理列表

路径：【开放服务云】→【OpenAPI】 → 【API管理】 ，点击“新增”按钮，创建自定义API（Java插件）。

![](https://vip.kingdee.com/download/010038f082539f824d2a8a032a9b604118d1.png)

### 2.2 维护自定义API信息

维护所属应用、类及方法名，系统自动加载请求参数和返回参数。若需发布为webservice接口，还可以维护webservice信息。

![](https://vip.kingdee.com/download/0100a40ff95e81ef4fe6a81bf46fb88981b1.png)

![](https://vip.kingdee.com/download/0100a08972c0ce9c486d9e12f4ad691e774e.png)

### 2.3 API在线测试

点击“API测试”按钮，打开API测试弹窗，在系统中实时调试API功能，测试完成后，将接口状态改为发布。

![](https://vip.kingdee.com/download/01000c0bdb7987784ca08489f3bfd1ce8bb3.png)
