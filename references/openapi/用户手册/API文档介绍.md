**1 简介**

**1.1 功能介绍**

API文档展示了OpenAPI的详细出入参、错误码信息以及JSON、XML、SOAP1.1、SOAP1.2四种格式的参数示例，简洁易读，帮助开发人员快速调用API接口。

**1.2 应用场景**

展示各个云和应用下的API文档，帮助用户快速进行了解并调用OpenAPI。

1.3 操作路径

【开放服务云】→【OpenAPI】→【API文档】

1.4 界面说明

API文档页面内容分为三部分：

- 左侧树状目录：位于页面左侧，目录层级为云-应用-业务对象-API名称；
- 内容区：内容区居中，展示详细的API文档信息，数据来源于启用的API服务。当用户新建并保存发布API服务时，接口文档会自动在API文档中展示；
- 锚点：位于页面右侧，用户可点击锚点，快速到达本页内相应的位置。
