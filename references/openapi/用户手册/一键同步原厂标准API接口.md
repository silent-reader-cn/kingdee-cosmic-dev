# 一键同步原厂标准API接口

1 简介

1.1 功能介绍

用户可在API管理页面轻松使用云更新功能，一键同步原厂提供的标准API接口。该功能让用户无需繁琐地升级补丁包，即可在线获取最新的原厂标准API接口，从而极大地提升了现场实施的效率。

**适用版本：V5.0.011（BOS）**

1.2 应用场景

客户按需同步苍穹、星瀚、金蝶AI套件的最新标准API接口，从而满足业务需求。

1.3 系统路径

【开放服务云】→【开放平台】→【API管理】

2 主要操作

步骤一 资源权限申请

用户当前环境首次使用此功能时，需要申请云端的资源访问权限。具体操作路径：【集成服务云】 → 【资源中心】 → 【应用密钥申请】

具体操作步骤：

（1）打开应用密钥申请页面。

（2）填写云端地址、云端账套等必要信息。

（3）在“AccessToken认证密钥”和“摘要认证密钥”字段中，点击刷新图标，以重新生成认证密钥。

（4）点击“保存”和“提交”按钮，完成申请。

（5）提交后，系统将提示申请正在审核中。通常等待30s后，点击“刷新”按钮，申请状态会更新为“申请成功”。至此，云端资源访问权限申请已完成。

![](https://vip.kingdee.com/download/010901c07a39a5aa47d7ad52587760da96c5.png)

*注意：*

- *如果当前环境已经申请过应用密钥，此步骤可跳过。*
- *云端生产环境地址为：https://resource.kdcloud.com/*
- *若点击“刷新”后状态未更新，可能是当前环境无许可或者许可不合法，此时资源权限申请将进入了人工审核环节。人工审核通常1天内完成，紧急情况下请联系 樊鑫 处理。*

步骤二 API在线云更新

云更新时，系统会自动对比云端与当前环境的API配置信息的差异，并将有差异的API接口展示在云更新列表中。每条数据上均明确标注了“更新类型”，以便用户了解API的云更新方式。

更新类型说明：

- 新增：若API在当前环境不存在，云更新将自动将其配置新增至当前环境。
- 覆盖：若API在云端存在新版本，云更新将用云端的新版本配置覆盖当前环境的配置。

具体操作步骤：

（1）进入OpenAPI应用，并打开API管理页面。

（2）点击列表上方的“云更新”按钮，进入云更新列表。

（3）在列表中搜索并勾选所需的API接口，然后点击“确认”按钮。

（4）系统将对所选API进行新增或覆盖处理，并实时反馈云更新结果。

（5）返回API管理列表，可看到所需API已同步至当前环境中。至此，用户即可使用最新的原厂标准API接口了。
