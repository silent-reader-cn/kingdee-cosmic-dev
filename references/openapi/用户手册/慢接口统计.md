# 慢接口统计

## 变更记录

| 产品版本 | 更新内容 | 更新日期 |

| V6.0.8 | 初始版本 | 2024年3月 |

1 简介

1.1 功能介绍

默认统计前一天响应时间超过10s的慢接口记录，帮助用户实时监控整体接口性能。

1.2 应用场景

帮助用户了解整体慢接口情况，及时优化接口性能，提升系统集成效率。

1.3 系统路径

【开放服务云】→【OpenAPI】→【API统计】→【慢接口统计】

1.4 按钮说明

| 按钮名称 | 详细解释 |
| --- | --- |
| 刷新 | 刷新当前页面。 |
| 退出 | 点击退出按钮，退出当前页面。 |

2 主要操作

2.1 查看慢接口统计

打开慢接口统计报表，慢接口统计信息默认每天定时统计前一天的慢接口（响应时间超过10s）数据。列表展示API名称、请求地址、慢接口次数、平均耗时、最大响应时间和统计时间等信息。

![](https://vip.kingdee.com/download/0109b6835e0900044730878a89cbc79add3a.png)

![](https://vip.kingdee.com/download/01095070b7d547144b1490ea0ab988547fe0.png)

### 2.2 查看慢接口日志

点击具体的API名称，系统自动跳转到API调用日志，用户可以直接查看详细的慢接口日志，并进一步分析接口性能问题。
