1 简介

**1.1 功能介绍**

通过统计信息报表和统计信息看板，可以让用户更直观地查看、筛选和过滤API服务的调用数据。

**1.2 应用场景**

帮助用户了解整体API接口的运行情况。

**1.3 系统路径**

【开放服务云】→【OpenAPI】→【API统计】→【统计信息】/【统计看板】

**1.****4****按钮说明**

| **按钮名称** | **详细解释** |
| --- | --- |
| 引出 | 点击引出按钮，导出当前API统计信息报表。 |
| 刷新 | 刷新当前页面。 |
| 报表配置 | 点击按钮，弹出弹窗可配置当前页面展示字段。 |
| 退出 | 点击退出按钮，退出当前页面。 |

**2 主要操作**

**2.1 查看统计信息**

打开API统计信息报表，API统计信息支持按时间、第三方应用和API维度展示。

![](https://vip.kingdee.com/download/0109c31779bed6704297a882b7be593d9a37.png)

![](https://vip.kingdee.com/download/01091e7ed1fef18141858e292df2868a27db.png)

![](https://vip.kingdee.com/download/0109243b3923700d45e38f5b17cc231ad164.png)

**2.****2****查看统计信息****看板**

打开API统计信息看板，统计信息看板界面上方展示**当日、近一周、近30天和近一年**的API调用次数，下方为API调用趋势分析图，支持按日或时进行趋势分析。

备注：统计数据非实时更新的，约30分钟自动更新。
