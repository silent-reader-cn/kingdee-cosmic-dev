1 简介

1.1 功能介绍

帮助手册主要展示了自定义API中需要用到的常用脚本或函数的用法，帮助用户快速上手API开发。

1.2 应用场景

当开发人员使用脚本开发API时，需要用到各种函数和脚本方法，此时可以查看脚本帮助手册，提升API开发效率。

1.3 系统路径

【开放服务云】→【OpenAPI】→【其他】→【帮助手册】

1.4 字段/按钮说明

字段说明：

| 字段名称 | 详细解释 |
| --- | --- |
| 编码 | 脚本编码 |
| 主题 | 脚本主题 |
| 作者 | 脚本编写的作者 |
| 适用场景 | 脚本的适用场景 |
| 分类 | 脚本的分类 |

按钮说明：

| 按钮名称 | 详细解释 |
| --- | --- |
| 退出 | 点击退出按钮，退出当前页面。 |

2 主要操作

用户可以通过输入关键字或选择分类来查看和过滤脚本，以便快速找到所需脚本的使用说明。
