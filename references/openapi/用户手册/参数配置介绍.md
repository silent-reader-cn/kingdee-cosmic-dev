**1 简介**

**1.1 功能介绍**

OpenAPI系统参数允许用户设置日志记录级别、显示异常stack、查询接口的最大查询数量等选项，提升OpenAPI应用的灵活性。

**1.2 应用场景**

通过可视化的参数配置，匹配用户在不同场景下的个性化需求。

**1.3 系统路径**

【基础服务云】→【公共设置】→【参数配置】→【系统参数】

**1.4 字段说明**

| **字段名称** | **详细解释** |
| --- | --- |
| 显示异常Stack | 当API服务调用失败时，是否在返回结果中展示stack堆栈信息。 |
| 大文本日志保存天数 | 大文本日志保存的时间，默认为5天，取值范围是[1,25] |
| 选择API调用日志级别 | 设置日志记录级别，根据实际需要选择合适的级别记录API日志 |
| 是否记录完整请求头 | 开启后，API调用日志会记录完整的请求头参数 |
| 是否统计API调用次数 | 控制是否统计API调用次数 |
| 查询参数-最大查询数量 | 控制查询操作接口的返回数量。当查询数据过大时，建议分页查询 |
| 慢接口阈值(ms) | 配置慢接口统计的阈值，默认10000ms，配置范围：3000~60000。如果配置为0，则不统计 |
| 自定义servlet功能 | 开启参数后，可以在API开发中新建自定义Servlet接口 |
| 扩展参数 | 通过特定的扩展参数启用OpenAPI的灰度功能 |
| 个性化导出API设置 | 维护导出API时需要忽略的字段，适用于导出时忽略敏感字段或高版本中新增的字段，确保数据平滑迁移。 |
| 多时区转换 | 开启后，API支持自动转换并返回带时区信息的时间。 |
| 返回UTC基准时间 | 开启后，API查询返回的时间将统一为UTC基准时间 |
| 禁止上传附件类型 | 通过自定义API上传附件时，禁止的附件类型 |
| 插件应用 | 插件所在应用 |
| 接口鉴权插件 | 接口鉴权插件 |
| API测试弹窗样式 | 分屏/模态 |
| 服务URL | 维护MCP服务实例 |

**2.1****显示异常****Stack**

当API服务调用报错时，可以使用参数控制是否显示异常堆栈信息。

![](https://vip-admin.kingdee.com/download/0100933898d16970487c8a78fc28c75d325a.jpg)

### 2.2 API调用日志

API默认记录摘要日志，可以通过参数配置，选择其他的日志级别，如不记录日志、记录摘要日志、记录详细日志、记录详细日志（大文本）。当选择不记录时，系统不会记录API的调用日志，请谨慎设置。

- 当记录摘要日志时，日志不会记录API的请求参数和返回参数。

![](https://vip-admin.kingdee.com/download/0109d9d528ddccb14293a176b905ee188245.png)

- 当记录详细日志时，日志会记录API的请求参数和返回参数，但最多只会存2000字符。

![](https://vip.kingdee.com/download/0109dec2416e9f5f46e7a8f2aa1028222414.png)

- 当记录大文本日志时，日志会记录全量的API请求参数和返回参数。

![](https://vip.kingdee.com/download/0109981f5438fefd4de3ad84b3b7cf12d931.png)

### 2.3是否统计API调用次数

该参数可控制是否统计API得调用次数，默认打开，当开关关闭时，系统不会继续记录API 统计信息，也不再更新OpenAPI内的统计看板。

![](https://vip.kingdee.com/download/0100cd6b5778dafc4aa8add26d1e0b92033f.jpg)

### 2.4查询参数-最大查询数量

通过该参数来控制查询操作的最大返回数据，接口单次返回数据量不超过参数值，当**数量过大时建议分页查询**。当最大查询数量参数设为X时，即使有数万条数据，最终接口也只返回符合条件的X条数据。

![](https://vip.kingdee.com/download/01008677ea96b97e42df81ef8648ef6d2232.jpg)
