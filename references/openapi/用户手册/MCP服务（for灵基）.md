## 1 功能介绍

**MCP服务**是苍穹平台**为灵基**提供的AI工具网关，通过将OpenAPI契约自动转化为MCP协议工具（Tool）的能力，以双层Token认证保障安全，使灵基能够以标准化方式调用苍穹业务 API。

平台在原【集群级MCP服务】基础上进行升级，支持**客户将二开 API** 发布为MCP服务，目前共两种服务来源：

- **系统内置**：由金蝶开发商发布，将金蝶标品API发布为 MCP 服务，面向全体租户开放。
- **租户自建**：由企业客户的 IT/实施团队自主配置，仅允许选择本租户的二开 API，工具可见范围限定在当前账套，实现企业个性化业务场景的智能化扩展。

**核心概念速览：**

| 概念 | 说明 |
| --- | --- |
| **MCP** | Model Context Protocol，AI 客户端与工具提供方之间的协议 |
| **工具（Tool）** | 一个可被 AI 发现与调用的业务接口抽象，由「工具定义（名称 / 描述 / 参数 schema / 调用方式）」构成 |
| **账套（account）** | 苍穹的独立业务数据库单元，本功能按账套隔离工具 |
| **Gateway** | MCP网关进程，自动读取数据并对外提供 MCP 服务 |

## 2 应用场景

适用于需要让灵基直接操作苍穹平台业务数据的场景：

- **标准业务场景**（系统内置）：金蝶标品预置的MCP服务，让智能体完成通用单据查询、数据录入、流程审批等标准化业务操作。
- **企业二开扩展场景**（租户自建）：企业将自定义的二开 API 发布为 MCP 服务，让智能体直接操作企业特有的业务单据和流程，无需为大模型单独定制 API 对接开发。

## 3 系统路径

【开放服务云】→【OpenAPI】→【MCP服务】→【MCP服务】

## 4 关键字段/按钮说明

### 4.1 关键字段说明

| **字段名称** | **详细解释** |
| --- | --- |
| API类型 | 支持的API引擎类型，API服务/RESTful API |
| 目标API | 手工录入，选择要发布的API服务。注意：租户目前只支持选择二开 API |
| 所属云编码 | API所属云编码 |
| 所属应用编码 | API所属应用编码 |
| 操作类型 | 如查询操作、创建操作、更新操作、删除操作等 |
| 是否敏感操作 | 标记MCP工具是否为敏感操作，方便智能体调用时进行二次确认 |
| 所属领域 | 语义化信息，MCP工具所属领域，如供应链云 |
| 所属模块 | 语义化信息，MCP工具所属模块，如采购管理 |
| 自定义参数扩展配置 | 若已有信息不满足大模型要求，可补充自定义参数，Map结构如：{"key":"value"} |
| 注册状态 | 待注册/已发布/待更新/下架中/已下架/失败。发布后若服务或API变更则变为待更新，异常为失败 |
| 服务来源 | 系统内置 / 租户自建 |
| 工具名称 | 工具唯一标识，按 `{domain}_{app}_{isvid}_{httpmethod}_{apiuri}` 规则生成，apiuri 中的"/"统一替换为"_"，最大长度 **55** 字符，超长自动截断并附加5位随机数。支持手动修改（建议调整 {apiuri} 部分以增强语义）。 |
| 说明 | MCP工具功能说明 |
| 前置条件 | MCP工具前置条件 |
| 后置效果 | MCP工具后置效果 |
| 错误恢复 | MCP工具错误恢复 |
| 异常日志 | 服务出现异常时的日志 |

### 4.2 关键按钮说明

| **按钮名称** | **详细解释** |
| --- | --- |
| 新增 | 点击按钮，打开新增MCP服务页面 |
| 重置注册状态 | 点击按钮，可将已下架或失败状态的MCP服务重置为待注册状态，等待MCP网关下次自动扫描（默认 5 分钟一次），重新注册发布 |
| 下架 | 点击按钮，下架状态为已发布的 MCP 服务 |
| 修改 | 点击按钮，修改MCP服务，**已发布和待更新状态**的MCP服务，**必须先下架**才允许修改。 |
| 导入YAML | 导入语义化契约YAML文件，快速生成 MCP 服务 |
| 导出MCP | 导出MCP服务为dts文件，支持单条或批量导出，用于跨环境数据迁移 |
| 导入MCP | 导入dts文件格式的MCP服务，支持单条或批量导入，用于跨环境数据迁移（**该能力不支持跨开发商标识的数据同步**，租户无法直接导入标准MCP服务）。 |
| 导出预置脚本 | 导出 MCP 服务的SQL脚本，方便在升级时通过脚本预置MCP服务 |

## 5 主要操作

### 5.1 新增 MCP 服务

登录金蝶AI苍穹环境，进入菜单 **开放服务云 → OpenAPI → MCP 服务** → **MCP 服务**，点击新增按钮，即可新增 MCP 服务。

![上传图片](https://vip.kingdee.com/download/0100cd19a988293142f6a53ce512f45a9c64.png)

**1）新增方式****：手工/导入**

| **方式** | **适合场景** |
| --- | --- |
| **手工新增** | 少量API快速接入，逐个配置 |
| **导入YAML** | 根据OpenAPI规范文档，通过skill生成规范的yaml文件，逐个导入 |
| **导入MCP（.dts）** | 跨环境批量迁移，一键搬家 |

**2）服务来源：****系统内置 vs 租户自建**

| **来源类型** | **谁发布？** | **谁可用？** | **适合场景** |
| --- | --- | --- | --- |
| **系统内置** | 金蝶开发商发布 | 全体租户开放 | 使用金蝶标品API即可满足 |
| **租户自建** | 企业IT/实施团队自主配置 | 仅限本账套 | 需要二开API定制化解决 |

- 注意：系统内置的 MCP 服务关联的接口均为标准 API；租户自建的 MCP 服务只允许关联二开 API（即开发商标识不为 kingdee 的 API）。

**3）权限控制**

租户环境（非金蝶标准环境）**仅支持维护租户自建的MCP服务**，**不能修改系统内置MCP服务**，**也无法通过导入YAML或导入MCP等方式新增金蝶标准系统内置的服务**— 导入功能仅限当前租户自建的服务，两种来源的MCP服务**相互独立**。

**4）语义化信息**

语义化字段包含有说明、操作类型、所属领域、所属模块、前置条件、后置效果、错误恢复。以上字段作为API契约的补充，帮助大模型更好地理解MCP工具。

同时有自动化规则：系统会将删除操作和反审核操作自动标记为敏感操作，在MCP工具列表中标记为sensitive。

> **工具提示**：语义化信息契约生成器下载地址：[https://skills.kingdee.com/skills/438](https://skills.kingdee.com/skills/438) **，**通过契约生成的 YAML 文件，业务开发人员应在导入前完成契约质量审核，确保生成的语义化信息易于理解。
>
> **特别注意：**苍穹9.0版本，**MCP服务不再保存原始YAML信息**，MCP工具中API相关信息，默认取自API契约，请规范维护API本身的请求参数，**避免出现$key以及$value 等虚参数**，影响大模型理解。

**5） 多语言**

MCP网关（mcp/gateway）默认返回英文**语言的工具信息（含工具说明、语义化信息、接口 inputSchema等）**；若对应字段没有英文翻译，则返回中文。无需额外参数，语言返回由服务端根据字段是否存在英文值决定。

![上传图片](https://vip.kingdee.com/download/01008c1e187f12d04e41bf6e4ff059c2eb49.png)

![上传图片](https://vip.kingdee.com/download/0100aa5162f2004f487592c654e5e670658c.png)

**6）导入/导出MCP**

若用户需要批量迁移自建的MCP服务，还可以通过导入/导出功能，进行跨环境之间的MCP服务数据迁移。

注意：导入/导出MCP服务，**不支持跨开发商标识的数据同步**，租户无法直接导入标准MCP服务。

### 5.2 MCP 服务自动注册

新增MCP 服务后，等待系统自动注册工具到苍穹 **MCP Gateway**（系统每 5 分钟自动扫描并注册MCP服务，无需手动触发），然后灵基后台即可拉取ERP侧最新的MCP服务。

**注意：**

- 若修改了 MCP 服务关联的 API 信息，该服务将自动转为「待更新」状态，等待下次 MCP 网关扫描（默认5分钟一次）时重新注册并刷新信息。
- 若标品更新了 API 字段，建议将对应 MCP 服务脚本中的状态手动改为「待注册（UNPUBLISH）」。否则，需客户手工下架该服务后，再将注册状态重置为「待注册」，才能使最新 API 信息生效。
- 灵基获取工具列表时，请求头会携带`cosmic_mcp_token`与`erpAccountId`（账套级MCP服务必传）；若缺失`erpAccountId`，会出现返回空列表、或只能查询到部分非 API 类工具的问题。

### 5.3 灵基对接MCP服务

详见[灵基操作手册：管理员配置与运维指南](https://www.kingdee.com/docs/lingee#admin-ops-guide)

参考上方配置文档，在灵基企业后台管理页维护好ERP相关参数，工具列表**自动同步**最新的ERP侧工具。

![上传图片](https://vip.kingdee.com/download/010069edd4d14bc4458b95e4772a4460733a.png)

接下来灵基用户只需创建一个 Skill（技能），就能用自然语言指挥ERP了。

> ② 按「运费支付方」维度自动分类整理

## 6 注意事项（苍穹9.0变更）

**MCP 服务升级为账套级**

- 苍穹 9.0 开始，集群级 MCP 服务升级为**账套级 MCP 服务**。MCP 与 API 的对应关系为**一对一**，同时支持用户新增二开MCP服务。Monitor日志查询的关键字为【McpAccountTool】。

**MCP中API相关信息默认取自API契约**

- 苍穹 V9.0版本，MCP服务不再保存原始YAML信息，但为保证兼容 — MCP的参数inputSchema仍会正常生成：有已保存yaml的优先读yaml，没有的**自动读API契约**（OpenAPI接口参数）。
- 已发布的历史MCP服务，如果脚本中yaml和API契约参数不一致，**不要随意删除yaml信息**！清除后会回退读取API契约，可能导致线上行为变更。正确做法是先把两者对齐再清理。
- 请规范维护API本身的请求参数，避免出现 `$key`、`$value` 等虚参数，以免影响大模型理解。
