# 预警配置

## 变更记录

| 产品版本 | 更新内容 | 更新日期 |
| --- | --- | --- |
| V6.0.8 | 初始版本 | 2024年3月 |

1 简介

1.1 功能介绍

预警配置支持配置消息渠道和消息模板，当集成接口出现慢接口等异常情况时，及时进行消息预警。

1.2 应用场景

帮助用户对性能较差的API接口进行定时监控和治理。

1.3 系统路径

【开放服务云】→【OpenAPI】→【API预警通知】→【预警配置】

1.4 按钮说明

| 按钮名称 | 详细解释 |
| --- | --- |
| 保存 | 点击按钮，保存预警配置 |
| 启用 | 点击按钮，启用预警配置 |
| 禁用 | 点击按钮，禁用预警配置 |
| 退出 | 点击按钮，退出当前页面 |

1.5 字段说明

| 按钮名称 | 详细解释 |
| --- | --- |
| 编码 | 预警配置编码 |
| 名称 | 预警配置名称 |
| 消息渠道 | 消息发送渠道，如钉钉、云之家、电子邮件等 |
| 消息接收人 | 预警消息的接收人 |
| 预警类型 | 默认为慢接口 |
| 使用状态 | 启用/禁用 |
| 标题 | 预警消息的标题 |
| 正文 | 预警消息的正文 |

2 主要操作

2.1 查看预警配置列表

打开预警配置列表，这里可以看到系统中已维护的预警配置。

![](https://vip.kingdee.com/download/0109c2f976784fe8457ca73e2d8d67218900.png)

### 2.2 新增预警配置

列表点击“新增”按钮，打开预警配置新增页面，维护编码、名称，消息渠道、接收人和消息内容等信息，保存预警配置。

注意：新维护的预警配置默认为禁用状态，需要点击“启用”按钮，预警配置才正式生效。

![](https://vip.kingdee.com/download/0109f1b589851b9a4897832853821fe0caa2.png)

配置完成后，每次系统自动统计慢接口时（详见[慢接口统计](https://vip.kingdee.com/article/561129544887976960)），会自动将消息，通过消息渠道自动发送到消息接收人。
