# 标准DELETE方法 - 删除资源

## 1 接口介绍

将业务对象的删除操作发布为RESTful API，通过资源唯一标识删除指定资源，仅支持删除 “暂存” 状态的数据（如未提交的采购订单），适用于外部系统清理无效业务数据的场景。

注意：删除接口的开放权限需严格管控、极度谨慎。数据一旦被外部第三方系统通过该接口执行删除操作，将立即被物理删除，且无任何回滚恢复机制！

## 2 接口示例

点击“快速创建”或“新增”按钮，新增RESTful API，“操作类型选择“删除”，“操作选择“删除”。

- **实体信息：**业务对象、操作类型和操作会根据创建向导中的配置自动带出；
- **维护基本信息：**名称：录入“删除采购订单（需体现业务语义）”；编码：系统自动生成，支持手工修改；所属应用：按业务对象关联自动带出；日志级别：默认记录基本日志，可选择 “详细日志”（记录出入参，便于故障排查）；详细描述：手工录入，如“根据主键删除采购订单”。
- **请求端点配置：**方法：DELETE资源路径：系统自动生成，支持修改；路由唯一标识：系统自动拼接。完整请求地址：系统自动拼接。
- **维护请求参数：**仅需 Path 参数，默认为资源的唯一标识，也就是主键“id”，字段类型为 “long”，系统自动生成示例值。
- **维护响应参数：**成功状态码 “200-OK”，返回id和delete_time（删除时间）异常场景：若资源为 “已提交” 状态，返回 400 错误，提示 “只能删除暂存的数据”。

点击 “保存”及“启用”按钮，API 即可对外调用。用户在获取到请求令牌后，可通过完整请求地址，传入资源唯一标识（id），删除资源。

若需批量删除，选择 “数据模式：批量”，请求方式改为 “POST”，请求体传入需删除的id列表（如{"id":["2184074116397546496","2184074116397546497"]}）
