# 标准GET方法 - 查询资源列表

## 1 接口介绍

将业务对象的批量资源查询操作发布为RESTful API，支持通过分页、过滤条件筛选数据（如按创建时间查询采购订单列表），支撑外部系统获取批量业务数据需求（如财务系统导出某时间段内的所有订单）。

## 2 接口示例

点击“快速创建”或“新增”按钮，新增列表查询操作的RESTful API，在详情页面维护API信息。

- **实体信息：**业务对象、操作类型和操作会根据创建向导中的配置自动带出，
- **维护基本信息：**名称：录入 “查询采购订单列表（需体现业务语义）；编码：系统自动生成，支持手工修改；所属应用：按业务对象关联自动带出；日志级别：默认记录基本日志，可选择 “详细日志”（记录出入参，便于故障排查）；详细描述：手工录入，如 “根据创建时间查询采购订单详情，包含单据编号、供应商、创建人等字段”。
- **请求端点配置：**方法：GET资源路径：系统自动生成，支持修改；路由唯一标识：系统自动拼接；完整请求地址 ：系统自动拼接。
- **维护请求参数（Query 参数）：**- “offset”：默认参数，整数类型，起始位置，默认值 “0”，示例值 “0”；- “limit”：默认参数，整数类型，每页条数，默认值 “10”，示例值 “10”；- “with_total”：默认参数，布尔类型，是否返回总条数，默认值 “false”（数据量大时建议不返回，避免影响性能）；- “createtime”：用户自定义参数，日期类型，创建时间（过滤条件），示例值 “2025-06-01T00:00:00Z”。
- **维护响应参数：**选择 HTTP 状态码 “200-OK”，点击 “添加字段”，勾选需返回的字段（如 “id”“billno”（单据编号）、“billstatus”（单据状态）、“billentry”（物料明细））；补充示例值（如 “billno” 示例 “CGDD-250601-001”）。列表查询时，响应报文在 pagination 字段中包含以下分页信息：- total：符合条件的总记录数。- offset：当前请求的起始位置（与请求参数一致）。- limit：当前请求的每页记录数（与请求参数一致）。- has_more：是否为最后一页（布尔值，便于前端判断是否显示 “下一页” 按钮）。
