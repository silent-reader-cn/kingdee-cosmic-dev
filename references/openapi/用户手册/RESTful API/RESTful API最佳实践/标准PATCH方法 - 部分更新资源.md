# 标准PATCH方法 - 部分更新资源

## 1 接口介绍

将业务对象的部分更新操作发布为 RESTful API，仅传入需修改的字段，适用于资源仅部分信息变更的场景（如采购订单仅修改单据编号、物料数量，无需变更其他字段）。

## 2 接口示例

点击“快速创建”或“新增”按钮，新增RESTful API，“操作类型选择“更新”，“操作选择“部分更新”。

- **实体信息：**业务对象、操作类型和操作会根据创建向导中的配置自动带出；
- **维护基本信息：**名称：录入 “更新采购订单物料备注和分录数量（需体现业务语义）”编码：系统自动生成，支持手工修改；所属应用：按业务对象关联自动带出；日志级别：默认记录基本日志，可选择 “详细日志”（记录出入参，便于故障排查）；详细描述：手工录入，如“更新采购订单备注和物料分录信息”。
- **请求端点配置：**方法：PATCH资源路径：系统自动生成，支持修改；路由唯一标识：系统自动拼接。完整请求地址：系统自动拼接。
- **维护请求参数：**Path 参数：id（必填，示例值 “2213965641793146880”）；请求体：仅添加需修改的字段（如billno（单据编号）、billentry（分录）、qty（分录物料数量）），无需传入完整资源数据，示例请求体：

```
{
  "billno" : "CGDD-250513-000001",
  "billentry" : [ {
    "id" : "2213965641793146880",
    "qty" : "999.0000000000"
  } ],
  "comment" : "Example"
}
```

- **维护响应参数：**成功时返回状态码 “200-OK”，返回id（更新资源 ID）和modify_time（更新时间）；异常状态码如“400- Bad Request”或“500-Internal Server Error”，接口会返回对应错误信息。

点击 “保存”和“启用”按钮，用户在获取到请求令牌后，可通过完整请求地址，传入部分字段，完成订单的部分信息更新。

备注：若需批量更新，在“数据模式” 选择 “批量”，请求体根类型变为 “数组”，请求体传入多条资源对象，同时需要在请求体中传入唯一资源标识id。
