# 自定义分类

1 简介

1.1 功能介绍

自定义分类是一种基础资料，用于标记自定义API的属性，在API管理列表的左侧树状结构中位于第三层（业务云和应用下）。

1.2 应用场景

帮助用户统一管理具有相同用途或特征的自定义API。

1.3 系统路径

【开放服务云】→【OpenAPI】→【其他】→【自定义分类】

### 1.4 字段/按钮说明

字段说明：

| 字段名称 | 详细解释 |
| --- | --- |
| 分类编码 | 编码 |
| 分类名称 | 名称 |
| 分类描述 | 描述 |

按钮说明：

| 按钮名称 | 详细解释 |
| --- | --- |
| 取消 | 退出当前页面。 |
| 保存 | 点击按钮，保存当前自定义分类，并关闭弹窗。 |
| 保存并新增 | 点击按钮，保存当前自定义分类，并清空弹窗字段。 |

2 主要操作

### 2.1 维护自定义分类

打开OpenAPI自定义分类，OpenAPI预置了一些通用的分类数据，用户也可根据实际需求，维护新的分类。

![](https://vip.kingdee.com/download/01093ec36756cc57474d9c4e231068854705.png)

点击“新增”按钮，维护自定义分类的编码、名称和描述，然后点击“保存”按钮，完成分类的创建。

![](https://vip.kingdee.com/download/01099f35cec1d94e49d19930a644cd1b5bca.png)

### 2.2 为自定义API维护分类

打开自定义API维护界面，为自定义API选择合适的分类并保存。

![](https://vip.kingdee.com/download/0109fb17e26e00a94a4bbb6755d48735e6bb.png)
