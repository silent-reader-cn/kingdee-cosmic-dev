# 代码片段管理介绍

| **产品版本** | **更新内容** | **更新日期** |

1 简介

1.1 功能介绍

OpenAPI预置了通用的数据库和微服务脚本，用户不仅可以使用预置的代码片段，还可以维护自己的代码片段，以便在基于脚本开发的自定义API中快速引用。

1.2 应用场景

帮助用户快速开发自定义API，提升接口开发效率。

1.3 系统路径

【开放服务云】→【OpenAPI】→【其他】→【代码片段管理】

### 1.4 字段/按钮说明

**字段说明：**

| 字段名称 | 详细解释 |
| --- | --- |
| 脚本名称 | 脚本的名称 |
| 脚本分类 | 脚本的分类 |
| 是否预置 | 是否预置脚本 |

按钮说明：

| 按钮名称 | 详细解释 |
| --- | --- |
| 保存 | 点击按钮，保存当前代码片段。 |
| 退出 | 点击退出按钮，退出当前页面。 |

2 主要操作

### 2.1 查看代码片段

进入OpenAPI应用，打开代码片段管理界面，可以看到预置的通用代码片段用。

![](https://vip.kingdee.com/download/01098f5a7ded7f474001ad030ab7a6291c45.png)

点击“新增”按钮后，会弹出代码片段维护窗口，用户可以在这里定义和保存常用的代码片段。

![](https://vip.kingdee.com/download/01093f28d457b1174deea96052d8a1b2ab5a.png)

### 2.2 开发自定义API

当用户在使用脚本开发自定义API时，也可以快速引用代码片段，并一键发布API。

![](https://vip.kingdee.com/download/0109576d356f430d44db956b87a4e41d80cf.png)
