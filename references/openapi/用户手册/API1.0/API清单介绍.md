# API清单介绍

1 简介

1.1 功能介绍

API清单是汇总展示金蝶AI苍穹各类服务接口（操作服务、自定义服务、AI服务）的文档入口，页面包含API基本信息、请求/返回参数，请求/返回示例等信息，帮助用户使用苍穹API服务。

1.2 应用场景

展示金蝶AI苍穹各个云和应用下的API接口文档，帮助用户进行API服务调用。

1.3 操作路径

路径：【开发服务云】→【开放平台】→【其他】→【API1.0】→【API清单】

1.4 界面说明

API清单左树层级按云-应用-API展示，右侧界面接口文档数据来源于API服务，当用户新建API服务并保存后，接口信息会自动展示在API清单中。
