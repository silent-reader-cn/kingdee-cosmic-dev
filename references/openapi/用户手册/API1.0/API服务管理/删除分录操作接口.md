# 删除分录操作接口

**1 接口介绍**

删除分录操作服务是指通过在请求体中按规范输入json格式的参数，调用服务给指定的单据或基础资料执行删除分录的保存操作。

**2 注意事项**

1）接口仅支持单条数据删除分录，暂时不支持子分录删除；

2）请求体中的参数**”entryName”**是分录标识，不同单据的分录及同一单据的不同分录，标识可能不同，需要特别注意。

3）若不确定需要删除的分录的id，可以先通过查询服务API，查到对应单据的分录内码。

**3 接口示例**

**采购订单删除分录**

| **URL：**{{host}}/kapi/sys/pm_purorderbill/deleteentryrows**请求方式：**POST**请求Header参数：**Content-Type=application/jsonaccessToken: xxxxxxxxxxxxx |
| --- |

| **请求Body：**{"entryName": "billentry","data": {"id": 1239845336667717632,"billentry": [{"id": 1239852533338406913},{"id": 1239852533338406915}]}} |
| --- |

| **请求结果：**{"data": {"success": true,"needSign": false,"needWfAssignPersons": false,"cancelWriteLog": true,"showMessage": true,"billCount": 1,"successPkIds": [1239845336667717632],"billNos": {"1239845336667717632": "CGDD-202109-152272"},"validateResult": {"validateErrors": [],"success": true,"message": "","errorPkIds": [],"errorDataIndexs": []},"allErrorOrValidateInfo": [],"runSecond": 0,"allErrorInfo": []},"success": true,"errorCode": "success","message": null} |
