# 加载操作接口

1 接口介绍

加载操作服务是指通过在url参数中指定某个具体的业务对象主键，调用服务按结构化返回该业务对象所有数据。

2 注意事项

加载服务仅支持加载单条数据，请求参数必须为主键”id”或”number”，接口会根据主键加载出该业务对象的所有明细信息。**当单据或基础资料中存在附件时，也可以通过加载接口得到该插件的相关信息，如url存放地址等。**
