# 追加分录操作接口

1 接口介绍

追加分录操作服务是指通过在请求体中按规范输入json格式的参数，调用服务给指定的单据或基础资料执行追加分录的保存操作。

2 注意事项

1）追加分录适用于一次给单据增加多条分录，系统根据主键自动在单据下新增分录，为保证接口性能，增加的分录数据不会和已有的分录做校验，但同一批追加的分录间会存在唯一性校验；

2）接口仅支持单条数据追加分录，暂时不支持子分录追加；

3）请求体中的参数”**entryName**”是分录标识，不同单据的分录及同一单据的不同分录，标识可能不同，需要特别注意。
