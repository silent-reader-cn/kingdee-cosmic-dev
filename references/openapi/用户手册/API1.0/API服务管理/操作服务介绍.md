# 操作服务介绍

1 简介

1.1 功能介绍

操作服务是将金蝶AI苍穹业务对象如单据、基础资料的操作（查询，保存，提交等）一键发布生成OpenAPI，同时系统自动生成服务接口及服务契约。

1.2 应用场景

1）发布苍穹标准服务接口供外部第三方应用调用；

2）预置标准接口，提供给苍穹其他模块调用。

1.3 操作路径

路径：【开发服务云】→【开放平台】→【其他】→【API1.0】→【API服务管理1.0】

2 主要操作

2.1 维护API基本信息

打开【API服务管理1.0】菜单，点击“新增”按钮，选择操作服务，进入到操作服务新增界面，录入API基本信息等字段，API请求地址自动生成。

![](https://vip.kingdee.com/download/010001739790696143fe8bbbb7483357ef9b.png)

![](https://vip.kingdee.com/download/01090bd9918582a2443cb69a14d2c63c2e92.png)

2.2 维护请求/返回参数（非必填）

在页面上维护请求参数，请求头部默认包含参数 Content-type和 assesstoken。若为get类请求，可维护Query参数及示例，若为POST类请求，可维护请求体参数及示例。

![](https://vip.kingdee.com/download/0100ab6d3b9b76b44aaa9d186aea4bf9452a.png)

![](https://vip.kingdee.com/download/01007e07c5023c59485aa8c3063938e5e802.png)

同样的方式在页面上维护接口返回参数，上一步维护的**请求参数示例**和**返回参数示例****仅作为参考**，实际返回的数据会按请求参数返回，各操作服务的**接口示例见文档最下方链接。**

![](https://vip.kingdee.com/download/0100c1f835b025f149c690e0fa837740f1ed.png)

2.3 注册插件（非必填）

插件一般用于自定义服务，系统支持java插件和自定义脚本插件。用户在操作服务也可以注册插件，在开放平台维护插件对应的路径来对接口返回数据进行干预。

点击“保存”按钮，该操作服务会自动展示在API清单中，接下来就可以进行API服务调用了。

![](https://vip.kingdee.com/download/0100110d923159b842108c4853dca5a72959.png)
