# 审核接口提示“单据已在流程中流转，不能审核”

## 1 问题描述

使用零代码配置的审核操作API，提示报错：单据已在流程中流转，不能审核，实际这个单据不应该进入工作流**。**

![](https://vip.kingdee.com/download/010926e513d76cab48a9ac7cb60452e7cdb6.png)

## 2 原因分析

会出现上面的场景都是因为这个单据配置了部分单据走工作流审批，部分单据不需要走工作流审批，当单据提交后，系统会逐一匹配工作流的启动条件，直到所有条件都匹配不上，寻址结束后才能进行审核。但是上面场景是提交后立马执行审核，寻址没有结束就会报如上的错误。

## 3 解决方案

若遇到上述场景，流程服务和OpenAPI均有提供解决方案，详细参考如下：

方案一：流程服务工作流解决方案，详见[审核操作提示“单据已在流程中流转，不能审核”的解决方案](https://developer.kingdee.com/article/553647116485340928?productLineId=29&isKnowledge=2&lang=zh-CN)；

方案二：OpenAPI自定义参数解决方案，通过参数跳过工作流，调用方在审核接口的请求body中，传入自定义参数WF，设为false ，即不进入工作流。示例：

{

"data": {

"billno": "unittest-20004124"

},

"optionvariables": {

"WF": "false"

}

}
