# 苍穹7.0的API导入低版本环境报错

## 问题描述

当用户通过OpenAPI 的导入功能，将苍穹7.0以上高版本的API（dts文件）导入到本地环境时，出现如下报错，提示字段插入表失败或长度超出限定范围。
![](https://vip.kingdee.com/download/0109f533603234a3408e93bab0398fa6d806.png)

![](https://vip.kingdee.com/download/0109ee2b739da1ea4dd58d949c28b595ed4b.png)

## 原因分析

- 为满足全球化需求，从苍穹 7.0 版本开始，OpenAPI 接口增加了对国际化多语言的支持，API 信息如名称、描述、请求/返回参数说明及示例等均为多语言字段，与早期版本相比存储了更多字符（包含英文、繁体等多语言信息）。因此，在导入时，旧版本字段长度设置过短，可能导致导入失败。
- 低版本 API 可导入到高版本环境，但支持多语言的 7.0 版本 API 在导入到不支持多语言的低版本环境时，可能会出现兼容性问题。

## 解决方案

- 建议用户进行 API 迁移时，选择相同版本的苍穹 API 进行导入导出操作，防止因版本元数据升级，导致数据无法迁移。
- 若苍穹版本高于7.0.6，可使用API多语言文件转换工具，对高版本的API处理后，即可正常导入。参考[API多语言文件转换工具介绍](https://developer.kingdee.com/knowledge/679319664643729152?productLineId=29&isKnowledge=2&lang=zh-CN)。
