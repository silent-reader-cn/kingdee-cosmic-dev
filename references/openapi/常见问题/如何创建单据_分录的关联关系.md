# 如何创建单据/分录的关联关系

## 1、问题描述

通过OpenAPI进行单据集成对接时，若单据存在上下游关系，特别是上游或下游单据是由第三方系统生成的情况下，应该如何产生关联？

## 2、解决方案

### 2.1、方案一：【下推】

**方案描述**：通过调用下推的API实现单据创建及自动关联

#### 2.1.1 调用对应单据提供的下推API：

API管理列表检索下推，优先选择已提供指定下推场景的API使用

![](https://vip-admin.kingdee.com/download/0109162de67f56074cfd8b2b23eaecd1b10b.png)

#### 2.1.2 通用下推并保存API

若对应单据，未单独开放对应下推API，可调用通用的下推并保存API，通过第三方应用中的服务授权，授权使用<基础数据服务API服务>后即可调用：

**通用下推并保存API特征：**

1. 支持：相同转换规则的批量下推、单个下推；

2. 支持：合并下推、整单下推，指定分录下推；

3. 不支持：拆单下推、下推同时修改数据。

注：拆单下推、下推同时修改数据，可采用2.1.3，下推同时修改数据可在下推完成后调用更新API满足。

![](https://vip.kingdee.com/download/0109e32d1404d852494aa2506f355136f821.png)

![](https://vip.kingdee.com/download/010925c679513fe049c59142fd864387c800.png)

#### 2.1.3 自定义下推并保存API

若以上下推未能满足项目需求，项目可自行通过Java插件进行封装BOTP的服务，实现所需的下推。

【自定义API介绍】：[https://vip.kingdee.com/knowledge/555460360946494464](https://vip.kingdee.com/knowledge/555460360946494464)

### 2.2、方案二：【关联子实体】

#### 2.2.1 方案说明

操作API支持在新增或更新数据时，通过关联子实体属性对单据或分录进行关联关系处理。

**注意事项：**

**由于该方案是高度依赖API调用方传入正确的参数及关联关系，若无法保证确认正确传入业务所需参数及关联关系，请采用下推方案；**

**因一旦参数漏传或关系错误**，将会**导致后续的业务操作报错或者出现数据问题**；

**故请采用此方案的项目，先在沙箱（或测试）环境进行充分测试并验证全流程后再进行生产启用对接！！！**

#### 2.2.2 方案描述

1. 操作API中，新增关联子实体属性，注意：图示为单据的关联子实体属性，如若是分录需要进行关联，则在对应分录下选择新增关联子实体属性![](https://vip.kingdee.com/download/01090442c747c8cb49348aa9d58d7e64c00f.png)
2. 按所需关联关系，正确入参，实现在新增或更新时添加上下游关联关系。

#### 2.2.3 字段说明：

| 字段 | 说明 |
| --- | --- |
| xxxx_lk_sbillid | 关联子实体.源单内码：上游单据id |
| xxxx_lk_sid | 关联子实体.源单主实体内码：看关联关系关联的是单头还是分录, 如果是单头则值为上游单据id，关联的分录则值为：上游单据关联分录对应行分录id |
| xxxx_lk_stableid | 关联子实体.源单主实体编码：可以在sys.meta库查 select ftableid,ftablename from T_META_EntityInfo where fid='pm_purplanbill'，固定值 ，看关联关系关联的是单头还是分录，然后根据ftablename对应表决定ftableid |

#### 2.2.4 其它说明

1. 关联子实体社区参考帖子：[https://vip.kingdee.com/article/444445234173120000?productLineId=29&isKnowledge=2&lang=zh-CN](https://vip.kingdee.com/article/444445234173120000?productLineId=29&isKnowledge=2&lang=zh-CN)

2. billentry_lk_stableid的获取方式：

1. 进入查询分析器；
2. 选择元数据库；
3. 执行sql（单据标识需要修改）：select * from T_META_EntityInfo where fid like '%单据标识%';
4. 取entitykey为分录的tableid![](https://vip.kingdee.com/download/0109ba5a9fda1b8841eeae03942a9077b9c4.png)

| 8 | 物料明细.核心单据行ID |
