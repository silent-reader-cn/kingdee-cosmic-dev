# 导出API文档

## 问题描述

当和第三方进行集成时，若对方无法登录苍穹平台，如何下载API文档给到第三方？

## 解决方法

- 路径：开放平台 - API管理 - API开发 ，进入API列表，勾选单条或多条API，点击导出按钮，选择导出PDF或swagger。即可生成离线文件，按需发给对接方。
